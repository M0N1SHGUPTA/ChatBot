## 1. 💬 Chat Endpoints (Client / Widget Integration)

### 1.1 Synchronous Chat
Submits a user question, uses the conversation history tied to `session_id` to rephrase queries, performs similarity search in ChromaDB, and returns an answer synthesized by Groq with cited sources.

- **Endpoint**: `POST /api/chat`
- **Content-Type**: `application/json`

#### Request Body
```json
{
  "message": "What is the key takeaway from the presentation?",
  "session_id": "user_12345"
}
```

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `message` | `string` | **Yes** | The user's input query. |
| `session_id` | `string` | No (default: `"visitor_default"`) | Unique identifier for tracking conversation history per user/session. |

#### Response (`200 OK`)
```json
{
  "answer": "The main takeaway from the presentation is...",
  "session_id": "user_12345",
  "sources": [
    "Semicon JIBB presentation.pdf"
  ]
}
```

#### JavaScript / TypeScript (Fetch) Example
```typescript
async function askChatbot(message: string, sessionId: string) {
  const response = await fetch("http://localhost:8000/api/chat", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      message: message,
      session_id: sessionId
    })
  });

  if (!response.ok) {
    throw new Error(`Chat error: ${response.statusText}`);
  }

  const data = await response.json();
  console.log("Answer:", data.answer);
  console.log("Sources:", data.sources);
  return data;
}
```

### 1.2 Streaming Chat (SSE - Real-Time Typing Effect)
Streams tokens as they are generated by the LLM in real time using Server-Sent Events (SSE).

- **Endpoint**: `POST /api/chat/stream`
- **Content-Type**: `application/json`
- **Response Format**: `text/event-stream`

#### Request Body
```json
{
  "message": "Summarize the document in 3 bullet points",
  "session_id": "user_12345"
}
```

#### Streamed Events
1. **Token chunks**:
   ```
   data: {"token": "The"}
   data: {"token": " following"}
   data: {"token": " are"}
   ```
2. **Final completion event**:
   ```
   data: {"sources": ["Semicon JIBB presentation.pdf"], "session_id": "user_12345", "done": true}
   ```

#### JavaScript / Next.js Client Implementation
```typescript
async function streamChat(message: string, sessionId: string, onToken: (token: string) => void) {
  const response = await fetch("http://localhost:8000/api/chat/stream", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      message: message,
      session_id: sessionId
    })
  });

  const reader = response.body?.getReader();
  if (!reader) return;

  const decoder = new TextDecoder();
  let buffer = "";

  while (true) {
    const { value, done } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split("\n\n");
    buffer = lines.pop() || "";

    for (const line of lines) {
      if (line.startsWith("data: ")) {
        const payload = JSON.parse(line.replace("data: ", ""));
        if (payload.token) {
          onToken(payload.token);
        }
        if (payload.done) {
          console.log("Stream completed. Sources:", payload.sources);
        }
      }
    }
  }
}
```

### 2.1 Upload Documents
Accepts one or more files, saves them into the `docs/` directory, chunks them, computes embeddings, and indexes them into ChromaDB.

- **Endpoint**: `POST /api/admin/upload`
- **Headers**:
  - `X-Admin-API-Key: <ADMIN_API_KEY>`
  - `Content-Type: multipart/form-data`
- **Form Data Field**: `files` (array of files)
- **Supported File Types**: `.pdf`, `.docx`, `.doc`, `.txt`, `.md`

#### cURL Example
```bash
curl -X POST "http://localhost:8000/api/admin/upload" \
  -H "X-Admin-API-Key: admin_secret_key_123" \
  -F "files=@/path/to/report.pdf" \
  -F "files=@/path/to/notes.txt"
```

#### TypeScript (FormData) Example
```typescript
async function uploadFiles(fileList: File[], adminKey: string) {
  const formData = new FormData();
  fileList.forEach(file => formData.append("files", file));

  const response = await fetch("http://localhost:8000/api/admin/upload", {
    method: "POST",
    headers: {
      "X-Admin-API-Key": adminKey
    },
    body: formData
  });

  return await response.json();
}
```

#### Response (`200 OK`)
```json
{
  "status": "completed",
  "total_files": 2,
  "total_chunks_added": 28,
  "files": [
    {
      "filename": "report.pdf",
      "status": "success",
      "size_bytes": 524288,
      "chunks_indexed": 20
    },
    {
      "filename": "notes.txt",
      "status": "success",
      "size_bytes": 1024,
      "chunks_indexed": 8
    }
  ]
}
```

### 2.3 Delete a Document
Removes the file from the filesystem and prunes all related embedding vectors from ChromaDB.

- **Endpoint**: `DELETE /api/admin/documents/{filename}`
- **Headers**: `X-Admin-API-Key: <ADMIN_API_KEY>`

#### cURL Example
```bash
curl -X DELETE "http://localhost:8000/api/admin/documents/sample.txt" \
  -H "X-Admin-API-Key: admin_secret_key_123"
```

#### Response (`200 OK`)
```json
{
  "status": "success",
  "message": "Deleted 'sample.txt' and removed 8 chunks from vector store."
}
```

---

### 3.2 Submit Visitor Lead Data
Submits the visitor's contact information and the service they clicked on. Data is stored in SQLite (`leads.db`) and mirrored to `leads.json`.

- **Endpoint**: `POST /api/leads`
- **Content-Type**: `application/json`

```json
{
  "session_id": "visitor_user_123",
  "name": "Sarah Connor",
  "email": "sarah@example.com",
  "service": "Partner Identification & Ecosystem Building",
  "notes": "Looking for Japanese robotics expansion"
```

| :--- | :--- | :--- | :--- |
| `session_id` | `string` | **Yes** | The session ID matching the visitor's current chat. |
| `name` | `string` | **Yes** | Visitor's full name (min length: 2). |
| `email` | `string` | **Yes** | Visitor's email address (validated). |

## ⚡ Frontend Integration Workflow (React / Next.js)

### How to trigger lead capture on the 2nd–3rd message:

1. When calling `POST /api/chat` or `POST /api/chat/stream`, inspect the response:
   - `res.message_count` (e.g., 2 or 3)
   - `res.trigger_lead_capture` (`true` when the visitor should see the form)
   - `res.services` (array of the 8 services)

2. Display your custom form / modal / button pills in your frontend:
```typescript
// types/chat.ts
export interface ChatResponse {
  answer: string;
  session_id: string;
  sources: string[];
  message_count: number;
  trigger_lead_capture: boolean;
  services?: string[];
}

export interface LeadSubmission {
  session_id: string;
  name: string;
  email: string;
  service: string;
  notes?: string;
}

// Submit lead function
export async function submitVisitorLead(lead: LeadSubmission) {
  const res = await fetch(`${API_BASE}/api/leads`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(lead)
  });
  return await res.json();
}
```
